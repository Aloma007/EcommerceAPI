# E-Commerce API 🛒

A RESTful API built with Python and FastAPI that serves as the backend for an e-commerce platform. It handles secure user authentication, product inventory management, user-specific shopping carts, and payment gateway integration using Stripe.

This project was built as part of the [roadmap.sh backend developer track](https://roadmap.sh/projects/ecommerce-api).

## Features

*   **User Authentication:** Secure signup and login functionality using hashed passwords (Bcrypt) and JSON Web Tokens (JWT) for route protection.
*   **Product Management:** Admin ability to add new products and user ability to view the entire catalog or search for specific items using query parameters.
*   **Shopping Cart Logic:** Authorized users can add items, view their personal cart, and remove specific items. Carts are strictly bound to the logged-in user's JWT.
*   **Payment Gateway Integration:** Calculates the cart total and securely communicates with the Stripe API to generate a checkout session URL.

## Tech Stack

*   **Language:** Python
*   **Framework:** FastAPI
*   **Authentication:** Passlib (Bcrypt), PyJWT, python-multipart
*   **Payments:** Stripe Python SDK
*   **Server:** Uvicorn
*   **Documentation:** Swagger UI (Auto-generated by FastAPI)

## Local Setup and Installation

Follow these steps to get the project running on your local machine.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aloma007/ecommerce-fastapi-backend.git
   cd ecommerce-fastapi-backend
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   
   # On Windows:
   venv\Scripts\activate
   
   # On Mac/Linux:
   source venv/bin/activate
   ```

3. **Install the dependencies:**
   ```bash
   pip install fastapi uvicorn "passlib[bcrypt]" bcrypt==3.2.2 PyJWT python-multipart stripe
   ```

4. **Run the development server:**
   ```bash
   uvicorn main:app --reload
   ```

5. **Access the API Documentation:**
   Open your browser and navigate to `http://127.0.0.1:8000/docs` to interact with the API using the built-in Swagger UI.

## API Endpoints Reference

**Authentication**
*   `POST /signup` - Register a new user
*   `POST /login` - Authenticate and receive a JWT

**Products**
*   `POST /products` - Add a new product to the catalog
*   `GET /products` - View all products (supports `?search_query=` parameter)

**Shopping Cart (Requires JWT)**
*   `POST /cart` - Add a product to the active user's cart
*   `GET /cart` - View the active user's cart
*   `DELETE /cart/{product_id}` - Remove a specific product from the cart

**Checkout (Requires JWT)**
*   `POST /checkout` - Process the cart and generate a Stripe checkout session
